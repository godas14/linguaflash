### 1. Умный выбор карточек ✅
**Файл:** `src/lib/cardSelection.ts` (196 строк)

**Функции:**
- `getDueCards(deckId, userId, limit)` — выбор карточек с приоритетом
  - 80% просроченных карточек (next_review <= NOW)
  - 20% новых карточек
  - Сортировка просроченных по срочности (oldest first)
  - Fallback на случайные карточки при ошибке

- `getDueCardsCount(userId, deckId?)` — подсчёт карточек на сегодня
  - Для одной колоды или всех колод
  - Используется в виджетах

- `getDueCardsCountByDeck(userId)` — подсчёт по каждой колоде
  - Возвращает Map<deck_id, count>
  - Для отображения в DueTodayWidget

### 2. Streak система ✅
**Файл:** `src/lib/streakUtils.ts` (65 строк)

**Функции:**
- `calculateStreak(lastStudyDate, currentStreak)` — расчёт серии
  - Первое изучение: streak = 1
  - Уже изучал сегодня: сохранить текущий streak
  - Вчера изучал: streak + 1
  - Пропустил день: streak = 1 (сброс)

- `getTodayDate()` — получить сегодняшнюю дату (YYYY-MM-DD)
- `hasStudiedToday(lastStudyDate)` — проверка изучения сегодня
- `daysBetween(date1, date2)` — разница в днях

## 🧠 Алгоритмы

### Smart Card Selection
```typescript
// Приоритет:
1. Просроченные карточки (next_review <= NOW)
   - Сортировка: oldest first
   - Берём 80% от лимита
2. Новые карточки (never studied)
   - Случайный порядок
   - Берём 20% от лимита
3. Перемешиваем финальный набор
```

### Streak Calculation
```typescript
if (!lastStudyDate) return 1              // Первый раз
if (lastStudyDate === today) return streak // Уже изучал
if (daysDiff === 1) return streak + 1     // Вчера изучал
else return 1                              // Пропустил → сброс
```
