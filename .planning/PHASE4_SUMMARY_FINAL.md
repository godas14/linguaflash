## 🎮 Пользовательский сценарий

```
1. Вход в систему
   ↓
2. Переход в "Колоды"
   ↓
3. Выбор колоды (например, "Comida y Bebidas")
   ↓
4. Просмотр статистики:
   - Всего карточек: 100
   - Новые: 95
   - Изучаются: 3
   - На повторение: 2
   ↓
5. Нажатие "Начать изучение"
   ↓
6. Изучение 20 карточек:
   - Показывается испанское слово
   - Клик → переворот → русский перевод
   - Самооценка (Снова/Сложно/Хорошо/Легко)
   - Следующая карточка
   ↓
7. Экран итогов:
   - Карточек изучено: 20
   - Точность: 85%
   - XP заработано: +200
   - Новый уровень: 2 (если достигнут порог)
```

## 🧠 Реализованные алгоритмы

### SM-2 Spaced Repetition
```
Качество оценки → Интервал повторения:
- Снова (0)     → 1 день
- Сложно (0.5)  → 3 дня
- Хорошо (1)    → 6 дней
- Легко (1.5)   → 10+ дней

Ease Factor: min 1.3, default 2.5
Формула: EF' = EF + (0.1 - (1.5 - q) * (0.08 + (1.5 - q) * 0.02))
```

### Система уровней
```
Level N требует: 100 * N^1.5 XP

Примеры:
- Level 1: 0 XP
- Level 2: 283 XP (28 сессий)
- Level 3: 520 XP (52 сессии)
- Level 4: 800 XP (80 сессий)
- Level 5: 1,118 XP (112 сессий)
```

## 💾 База данных

### Обновления при изучении

**Создание сессии:**
```sql
INSERT INTO study_sessions (user_id, deck_id, mode, started_at)
VALUES (?, ?, 'flashcard', NOW());
```

**После каждой карточки:**
```sql
INSERT INTO user_card_progress (user_id, card_id, state, ease_factor, interval, next_review, ...)
VALUES (?, ?, 'learning', 2.5, 1, NOW() + INTERVAL '1 day', ...)
ON CONFLICT (user_id, card_id) DO UPDATE ...;
```

**Завершение сессии:**
```sql
UPDATE study_sessions 
SET cards_studied = 20, correct_answers = 17, xp_earned = 200, completed_at = NOW()
WHERE id = ?;

UPDATE profiles 
SET xp = xp + 200, level = ?, last_study_date = CURRENT_DATE
WHERE id = ?;
```
