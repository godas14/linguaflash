## Реализованные алгоритмы

### SM-2 Spaced Repetition
```
Снова (0)   → 1 день
Сложно (0.5) → 3 дня
Хорошо (1)   → 6 дней
Легко (1.5)  → 10+ дней
```

### Система уровней
```
Level 1: 0 XP
Level 2: 283 XP (28 сессий)
Level 3: 520 XP (52 сессии)
Level 4: 800 XP (80 сессий)
```

---

## Пользовательский сценарий

```
1. /decks → выбор колоды
2. /deck/:id → просмотр статистики → "Начать изучение"
3. /study/:id → изучение 20 карточек:
   - Показывается испанское слово
   - Клик → переворот → русский перевод
   - Самооценка (Снова/Сложно/Хорошо/Легко)
   - Следующая карточка
4. Итоги сессии:
   - Карточек изучено: 20
   - Точность: X%
   - XP заработано: +200
```

---

## База данных

### Таблицы используются:
- **`user_card_progress`** — прогресс по каждой карточке
- **`study_sessions`** — история сессий
- **`profiles`** — XP и уровень пользователя

### Обновления при изучении:
1. Создаётся запись в `study_sessions`
2. После каждой карточки обновляется `user_card_progress`
3. В конце сессии обновляется `profiles` (XP, level)
