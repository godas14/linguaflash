## 🎓 Ключевые решения

### Архитектурные
- React + TypeScript для типобезопасности
- Supabase для быстрого backend
- Zustand для простого state management
- Tailwind для быстрой разработки UI

### Алгоритмические
- SM-2 для spaced repetition
- 80/20 для smart card selection
- Levenshtein distance для fuzzy matching
- Level N = 100 * N^1.5 для прогрессии

### UX
- 3 режима для разнообразия
- Instant feedback в Quiz/Type
- Confetti для celebration
- Progress bars для мотивации
